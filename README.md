## 🌟 Proyectos Destacados en Producción

### 1. 📦 Sistema ERP ICO Logística
Plataforma web de gran escala desarrollada para la automatización operativa y comercial de la empresa **ICO Logística S.A.C.**.

- **Backend:** **Java 21** con **Spring Boot 3** (Spring Data JPA, Spring Security, JWT, RESTful APIs).
- **Frontend:** **Angular 18** con TypeScript y Tailwind CSS.
- **Base de Datos:** **Microsoft SQL Server**.
- **Módulos Principales:**
  - **Módulo Comercial:** Gestión de clientes, historial de visitas/interacciones y cotizaciones automatizadas con **generación dinámica de PDF** (jsPDF).
  - **Módulo de Sistemas TI & Control de Activos:** Registro relacional de inventario físico (laptops, celulares, periféricos), **autogenerador dinámico de códigos patrimoniales** (`ICO-LAP-`, `ICO-CEL-`) e historial de asignaciones con **firmas digitalizadas en PDF**.

---

### 2. 👥 Ecosistema de Control de Asistencia RRHH
Solución híbrida para la gestión centralizada del personal y marcación de asistencia.

- **Aplicación Móvil:** Desarrollada en **.NET MAUI** para registro de marcaciones de horario con geolocalización.
- **Panel Web Administrativo:** Desarrollado en **Angular** con backend RESTful en **Spring Boot / .NET 10** y persistencia en **SQL Server**.

### 3. 📱 CRM Web & App Móvil Comercial
Sistema de gestión comercial para fuerza de ventas en campo y seguimiento en oficina.

- **CRM Web Back Office:** Plataforma web administrativa en **Angular** y **Spring Boot** para supervisión comercial en tiempo real.

## 🛡️ Seguridad & Buenas Prácticas (Sanitización de Datos)

En cumplimiento estricto con las buenas prácticas de seguridad de software y confidencialidad empresarial:

- 🔒 **Sin Datos Sensibles:** Ningún nombre de usuario, contraseña de base de datos, clave secreta JWT o dirección IP privada de servidores en producción está presente en este repositorio público.
